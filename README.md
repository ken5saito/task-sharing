# Task Sharing

## 概要

- シンプルなタスク管理共有アプリ
- 主な機能
  - タスク管理：タスクを作成・編集・削除し、完了状態を管理
  - タスク共有：メールアドレスでタスクを他のユーザーと共有
  - ログイン認証：メールアドレスとパスワードでログイン

## URL

https://task-sharing-henna.vercel.app/

## 技術スタック

- Next.js 15.5.10
  - React ベースのフレームワーク
  - ルーティング機能
- React 19.1.0
  - UI 構築ライブラリ
- TypeScript 5.8.3
  - JavaScript を拡張した静的型付け言語
- Redux Toolkit 2.9.0
  - アプリ全体の状態管理
- Tailwind
  - スタイル設定
- Next Auth
  - ログイン認証機能
- Firebase
  - リアルタイムデータベース機能

## クローン後の利用コマンド例

- 依存パッケージインストール
  - npm install
- 動作確認(localhost)
  - npm run dev
- ビルド
  - npm run build

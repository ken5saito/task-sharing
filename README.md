# Task Sharing

## 概要

- 複数人でタスク管理ができる Web アプリケーション
- タスクの作成、共有、編集、完了状態の管理が可能

## 技術スタック

- Next.js 15.5.10
  - React ベースのフレームワーク
  - ルーティング機能
- React 19.1.0
  - UI 構築ライブラリ
- TypeScript 5.8.3
  - JavaScript を拡張した静的型付け言語
- Redux Toolkit 2.9.0
  - アプリ全体の状態管理
- Tailwind
  - スタイル設定
- Next Auth
  - ログイン認証機能

## クローン後の利用コマンド例

- 依存パッケージインストール
  - npm install
- 動作確認(localhost)
  - npm run dev
- ビルド
  - npm run build
